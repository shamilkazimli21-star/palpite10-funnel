# Palpite10 Funnel

Mobile-first Brazilian football funnel for Palpite10.

The funnel contains:

- Landing page
- 4-question quiz
- Qualified result
- Borderline result
- Telegram redirect
- Disqualified Telegram installation flow
- Meta Pixel
- Meta Conversions API
- GA4
- SPA routing
- Persistent quiz state
- Mobile haptic feedback
- Mobile-safe-area support
- Responsive desktop layout
- Vercel deployment

No framework.
No npm.
No build step.
